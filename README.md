# 보험 레이더

개인 보험의 약관·제도·보험료 변경과 시행 시점, 새 소식과 업계 동향을 모으는 정적 사이트입니다. 매일 09:00 KST에 GitHub Actions가 수집·가공·요약·빌드하고 GitHub Pages로 배포합니다.

## 로컬 실행

Node.js 24 이상이 필요합니다. TypeScript는 Node의 타입 스트리핑으로 실행합니다.

```sh
npm ci && npm run collect && npm run analyze && npm run build && npm run serve
```

브라우저에서 http://localhost:5173 을 엽니다. AI 키 없이도 수집·가공·빌드가 동작합니다. 요약을 원하면 `GEMINI_API_KEY`를 환경변수로 설정하고 analyze와 build 사이에 `npm run summarize`를 실행합니다. 날짜는 KST 오늘이며 `IR_DATE=2026-10-23`처럼 지정하면 해당 날짜로 재실행합니다. 처음 실행할 때는 설정의 채우기 범위까지 수집합니다.

```sh
npm test
npm run typecheck
```

## 출처

- 금융위원회 보도자료·입법 및 규정변경예고, 금융감독원 보도자료·소비자경보
- 손해보험협회 보도자료·자동차보험료 조정 공시, 생명보험협회, 보험연구원
- 한화생명, 교보생명, 삼성화재, 메리츠화재 보도자료
- 한국보험신문, 보험신보, 보험저널, 보험매일 RSS

출처별 이름·종류·사용 여부는 `config.json`에서 관리합니다. 출처 하나가 실패하거나 0건을 반환해도 나머지 수집은 계속하며 화면에 상태를 표시합니다.

네이버 뉴스 검색 API는 기본적으로 꺼져 있습니다. 사용하려면 `config.json`의 `naver` 항목을 `enabled: true`로 바꾸고 저장소 Actions Secrets에 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`을 추가합니다. 로컬에서는 같은 이름의 환경변수를 설정합니다. 키가 하나라도 없으면 해당 출처를 건너뜁니다.

## 데이터 원칙과 저장

지어낸 데이터나 시안용 소식은 넣지 않습니다. 자료가 없으면 빈 상태를 표시합니다. 기업보험과 보험에 무관한 소식은 제외합니다. 같은 글의 출처 ID를 기록하여 여러 날 재수집되어도 처음 본 날에만 새 소식으로 묶습니다.

정확한 시행일은 원문에 연·월·일이 모두 있거나 공시표에 날짜가 있을 때만 씁니다. `7.1일부터`, `오는 25일부터`, `다음 달부터` 같은 표현에 연도나 날짜를 붙이지 않습니다. 연도가 있는 월·분기·반기 등 명시된 기간만 기간 막대로 표시하고, 입법·규정변경예고는 확정된 변경과 구분합니다. AI 요약은 원문 근거를 검증하며 키나 검증 결과가 없으면 제목·출처·원문 링크를 제공합니다.

`data/raw/`는 수집 메타데이터, `data/daily/`는 날짜별 소식 묶음입니다. `data/changes.json`은 누적 변경, `data/rates.json`은 최신 공시표, `data/seen.json`은 글별 첫 수집일, `data/pending-ai.json`은 요약·판정 대기 목록입니다. 변경은 정확한 시행일 또는 기간 종료일부터 183일, 미확정 표현은 발표일부터 183일 동안 보관합니다.

기사·PDF 본문은 커밋하지 않고 gitignore된 `tmp/bodies/{날짜}.json`에만 임시 저장합니다. 빌드 결과 `web/data/latest.json`도 커밋하지 않습니다. 빌드는 최근 30일 보고서를 모아 화면 데이터를 검증하며, 같은 날 가공을 다시 실행해도 기존 묶음과 요약을 보존합니다.

## 자동 배포

GitHub Pages의 Source를 **GitHub Actions**로 설정합니다. 요약을 쓰려면 저장소 Secret `GEMINI_API_KEY`를 추가합니다. 첫 실행은 Actions의 보험 레이더 갱신 워크플로를 수동 실행합니다. 이후 매일 수집하고, `main`의 `src/**` 또는 `web/**` 변경 때에는 빌드·배포만 합니다. 수집 데이터만 커밋하며 요약 실패는 배포를 막지 않습니다.

## 고지

이 사이트는 공개된 보도자료와 기사를 자동으로 모아 보여 주는 정보 제공용이며, 보험 가입이나 해지를 권유하지 않습니다. 요약은 AI가 만들었으므로 정확한 내용은 반드시 원문과 약관에서 확인하세요.
